# Privacy Policy for Passport Photo Studio Pro

**Effective Date:** October 29, 2026  
**Developer:** Kishan Kumar ([@kkrkishan](https://github.com/kkrkishan))  
**Application:** Passport Photo Studio Pro for Windows

---

## 1. Overview
Passport Photo Studio Pro is a professional desktop application designed for Windows 10 and Windows 11. We are deeply committed to protecting your privacy. This Privacy Policy explains our practices regarding user data, photographs, and scanned documents.

---

## 2. 100% Offline & Local Processing Guarantee
- **No Cloud Uploads**: All photo editing, biometric facial alignment, cropping, background adjustments, document scanning, perspective corrections, image compression, DPI configuration, and PDF generation are executed strictly **locally on your device**.
- **No Remote Transmission**: Your original photos, cropped pictures, signatures, scanned identity cards, and exported documents **never leave your personal computer**. They are never uploaded or transmitted to any external server or cloud service.

---

## 3. Data Collection and Usage
- **Personal Data**: Passport Photo Studio Pro does **NOT** collect, request, harvest, or store any personal data, names, addresses, or identification numbers.
- **Biometric Data**: Any face alignment or cropping guides in the software are processed solely in temporary device memory (RAM) while you edit. No facial templates, biometric models, or biometric hashes are collected or shared.
- **Analytics & Tracking**: We do **NOT** use any third-party tracking libraries, telemetry SDKs, Google Analytics, or advertising trackers.

---

## 4. Updates & Internet Connection
- The application periodically checks for software updates by querying public release information on GitHub (`api.github.com/repos/kkrkishan/passport-photo-studio-pro/releases/latest`) to inform you when a newer version or bug fix is available.
- No user-identifying parameters, hardware identifiers, or personal data are included during the update check.
- When installed via the **Microsoft Store**, updates are securely managed and delivered directly by Microsoft's standard Windows Store infrastructure.

---

## 5. File System Permissions
The application only accesses files and folders that you explicitly choose through native Windows Open/Save file dialogs:
- To open images or documents you wish to edit.
- To save exported photographs, print sheets (4×6", A4), or PDF files to your chosen folder (such as Downloads or Pictures).

---

## 6. Children's Privacy
Passport Photo Studio Pro does not target or solicit information from anyone under the age of 13. The application is family-friendly and safe for users of all ages.
