## 🌟 Overview

**Passport Photo Studio Pro** is a modern, native-grade Windows desktop application built with Electron, React, TypeScript, and Tailwind CSS. Designed specifically for photo studios, cyber cafes, digital service centers, and home users, it combines two specialized studios into a single offline-capable desktop powerhouse:

1. **Passport Photo Studio**:
   - Official biometric size presets (35×45 mm India/Schengen/UK, 2×2 inch US Visa/OCI, 30×40 mm ID, 51×51 mm, and Custom).
   - Biometric Face Alignment Guides (crown of head, eye line, chin line) calibrated to ISO/IEC 19794-5 and ICAO Doc 9303 standards.
   - Smart Studio Background replacement (Pure White, Studio Blue, Light Gray, Off-White, Navy, Custom Color).
   - Non-destructive image tuning: Brightness, Contrast, Saturation, Exposure, Highlights, Shadows, White Balance, Sharpness (unsharp mask convolution), and 1-Click Auto Enhance.
   - Dynamic Sheet Engine: Print 8 photos on 4×6" photo paper or up to 30–50+ photos on standard A4 paper with precision scissor cut marks and borders.

2. **Document Scanner Studio**:
   - Dual-slot architecture: **FRONT SIDE** and **BACK SIDE**.
   - Draggable 4-corner perspective rectifying engine (8-parameter projective homography) with real-time circular 3.5× magnifier loupe.
   - Automated edge boundary detection with Sobel luminance gradient profiling.
   - Document enhancement filters: Magic Document Color, Crisp Black & White binarizer, Smooth Grayscale, and Micro-Text Sharpness booster.
   - 1-Click **CREATE A4 SHEET**: Arranges Front on Top + Back on Bottom (or Side-by-Side) at exact 1:1 physical card scale (85.6 × 54 mm standard ID-1, Jan Aadhaar, etc.).
   - Multi-document set management (e.g., Person 1, Person 2, Person 3) exported as a unified multi-page A4 PDF.

3. **Desktop & Privacy Integration**:
   - 100% Offline operation: No photos, sensitive documents, or biometric data are ever sent over the internet.
   - Print-ready PDF export via `jspdf` with 100% physical scale preservation (zero stretching distortion).
   - 300 DPI and 600 DPI High-Resolution JPG / PNG image export.
   - Native `.ppsp` project file format for saving and reopening workspaces.
   - Custom Windows frameless titlebar with native system controls (Minimize, Maximize, Close, File Menu, Print dialog).

## 🛠️ Development & Building from Source

### Prerequisites
- Windows 10 or 11 (64-bit)
- Node.js v18+ or v20+ (Node v24 supported)
- npm or pnpm

### 1. Install Dependencies
```bash
cd passport-photo-studio-pro
npm install
```

### 2. Run in Development Mode
```bash
# Start Vite development server
npm run dev

# Start Electron development app
npm run electron:dev
```

### 3. Build Production Executables & Installer
```bash
# Run TypeScript typechecks and production compilation
npm run build

# Generate Windows NSIS Installer (.exe)
npm run package
```
Output:
- Installer: `release/PassportPhotoStudioPro-Setup.exe`
- Unpacked Windows binary: `release/win-unpacked/Passport Photo Studio Pro.exe`

## 🔒 Security & Privacy Architecture
- Electron `contextIsolation: true` and `nodeIntegration: false`.
- Secure preload IPC bridge (`window.electronAPI`) with strict channel validation.
- All image transformations, homography matrix solutions, and PDF renders take place in-memory via HTML Canvas and Web APIs.
- Zero external network requests required for any core feature.
